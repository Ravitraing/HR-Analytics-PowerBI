# HR Analytics Dashboard | Power BI

## Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to explore workforce data and identify meaningful HR insights.

## Key Features
- Total and Active Employees
- Employee Attrition Count and Rate
- Department-wise Attrition Analysis
- Salary Slab Analysis
- Age and Gender Distribution
- Employee Experience and Job Satisfaction

## Tools Used
- Microsoft Power BI
- Data Visualization
- HR Data Analysis
